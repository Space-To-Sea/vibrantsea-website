Automation Pipeline

Previously, the entire process of creating a visualization of one date manually took multiple hours and intensive care. This causes the process to complete each date very gradually, and other methods would be preferred to speed up the process. As a result, we have created an automation pipeline that completes the destriping much faster than if a person tried it by hand.

The Pipeline

The automation pipeline consists of multiple Python files and packages. Firstly, a Python script inputs a date and retrieves the satellite Landsat data by placing an order on the ESPA website. The script automatically downloads the data and creates a CSV that describes the phytoplankton concentration in four regions of interest. Afterwards, it processes the raw satellite data to make initial RBG images of the different types of phytoplankton through L2gen. Finally, the post-processing pipeline rotates, interpolates, and destripes those images, which mimics the manual Photoshop process that takes hours.

What Next?

Through the pipeline, we will be able to drastically minimize the time it takes to make visualizations. We are currently working on further improving the pipeline by perfecting the destriping algorithm through various methods. By implementing these improvements, we hope to create the most accurate visualizations to date.
